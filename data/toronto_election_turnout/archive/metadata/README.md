# Project Metadata

This folder stores project-level inventories that cut across research modules.

`variable_registry.csv` is the master register for modelling variables to be
collected or engineered later. It should track the intended source, processing
location, geography, denominator, and current status for each variable.

Module-specific QA metadata should stay with the module that produces it, such
as `elections/processed/metadata/` or `interpolation/processed/intermediate/`.
