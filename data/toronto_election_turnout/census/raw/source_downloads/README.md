# Census Raw Source Downloads

Some official Statistics Canada source downloads are not committed because they
are larger than GitHub's normal file-size limit. The processed Toronto outputs
and metadata are committed; these raw files can be downloaded again if a full
source rebuild is needed.

Download and place the files here:

| Local file | Source |
| --- | --- |
| `statcan_2021_ct_profile.zip` | https://www12-2021.statcan.gc.ca/census-recensement/2021/dp-pd/prof/details/download-telecharger/comp/GetFile.cfm?Lang=E&FILETYPE=CSV&GEONO=007 |
| `statcan_2021_ct_profile_ci.zip` | https://www12-2021.statcan.gc.ca/census-recensement/2021/dp-pd/prof/details/download-telecharger/comp/GetFile.cfm?Lang=E&FILETYPE=CSV&GEONO=007CI |
